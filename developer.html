ผู้พัฒนาระบบ

School Map Website · โรงเรียนวัดป่าประดู่

HTML5 CSS3 Vanilla JavaScript Responsive Design Dark / Light Mode

เกี่ยวกับโปรเจกต์

School Map คือระบบแผนที่โรงเรียนแบบโต้ตอบ สำหรับโรงเรียนวัดป่าประดู่ พัฒนาด้วย HTML5, CSS3 และ Vanilla JavaScript ล้วน ไม่พึ่งพา Framework ใดๆ

ผู้ใช้งานสามารถค้นหาห้องเรียน อาคาร ชั้นเรียน ได้อย่างรวดเร็ว พร้อมระบบ Zoom และ Drag เหมือน Google Maps รองรับ Dark/Light Mode และ Responsive Design บนทุกอุปกรณ์

ข้อมูลอาคารและห้องเรียนทั้งหมดจัดเก็บใน data/buildings.js ซึ่งสามารถแก้ไขได้ง่ายโดยไม่ต้องแตะ HTML หรือ CSS

วิธีแก้ไขข้อมูล

  1. เปิดไฟล์ data/buildings.js
  2. แก้ไขข้อมูลในอาร์เรย์ BUILDINGS
  3. แต่ละ building มี id, name, nameEn, color, floors
  4. แต่ละ floor มี floor (เลข), label (ข้อความ), rooms
  5. แต่ละ room มี id, number (ไม่บังคับ), name, type
  6. บันทึกไฟล์ รีเฟรชเบราว์เซอร์ — เสร็จสิ้น ✅
💡 เปลี่ยนรูปแผนที่: เพียงแทนที่ไฟล์ images/school-map.png ด้วยภาพแผนผังใหม่ ขนาดแนะนำ 1200×800 px ขึ้นไป
